## 이렇게 일합니다

**비용을 제약 조건으로 두고 설계합니다**
> COGI의 비로그인 체험 기능에서 AI 호출 비용을 제한해야 했습니다. Redis의 만료 시간과 횟수 제한을 사용해 별도 스케줄러 없이 체험 정책을 구현했습니다.

**환경 차이를 비즈니스 로직 밖으로 분리합니다**
> PotatoChip에서 개발 환경과 운영 환경의 파일 저장소가 달랐습니다. 저장 방식을 인터페이스로 추상화해 설정만으로 전환할 수 있도록 구성했습니다.

**결정을 기록으로 남깁니다**
> 팀의 진행 상황과 변경 사항을 문서와 PR로 공유했습니다. 코드만으로는 드러나지 않는 선택의 배경을 함께 남기는 것을 중요하게 생각합니다.
